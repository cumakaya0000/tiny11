# NEXUS PC 0.1.0

Initial development build.

- Dashboard with Windows, memory and disk summary.
- Read-only system analysis for processor, memory, graphics adapters and fixed disks.
- Local Ollama model listing, download progress and cancellation, confirmed model removal, and local chat test.
- Per-model local chat history with explicit clearing and configurable Ollama keep-alive.
- Allowlisted per-user Windows suggestions and taskbar Widgets changes with original-value backups and guarded rollback.
- Self-contained x64 Windows publish and Inno Setup installer definition.

This build is unsigned. Several optimization and update features are still under development.
